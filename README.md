# firewall_ips_listing

Resolve and list all IPv4/IPv6 addresses for a set of domains, grouped by
domain. Output is JSON with a `last_seen` timestamp per IP, designed to feed
firewall allowlists (e.g. OPNsense) that need to survive aggressive DNS
round-robin churn.

## Usage

```bash
./grab_ip.sh                  # default: 30-day retention purge
./grab_ip.sh --retention 60   # purge IPs not seen in the last 60 days
./grab_ip.sh --retention 0    # disable purge (keep everything forever)
```

The script iterates over every `.txt` file in `domains/`, resolves each
host's `A` and `AAAA` records, validates them, and merges the results into
`target/<name>.json`.

## Dependencies

| Tool | Purpose
|---|---|
| `bash` >= 4 | `${BASH_SOURCE}`, `read -ra`
| `dig` | DNS resolution (A + AAAA)
| `jq` | JSON merge / purge

IPv4 and IPv6 validation is done in pure bash (regex + octet/group counting).

## Adding a domain group

Create a `.txt` file in `domains/` with one hostname per line:

```
domains/myprovider.txt
    api.myprovider.com
    cdn.myprovider.com
```

On the next run, `target/myprovider.json` is created with the resolved
IPs.

## Output format

Each run produces `target/<name>.json`:

```json
{
  "domain": "tesla",
  "updated": "2026-09-04T10:18:13Z",
  "ips": [
    { "ip": "3.69.78.245", "type": "v4", "last_seen": "2026-09-04T10:18:13Z" },
    { "ip": "2001:db8::1", "type": "v6", "last_seen": "2026-09-04T10:18:13Z" }
  ]
}
```

- `ip` — the resolved address
- `type` — `v4` (A record) or `v6` (AAAA record)
- `last_seen` — ISO 8601 UTC timestamp of the last run that resolved this IP

## Merge and purge behavior

Each run resolves current IPs and merges them with the existing JSON:

- **IP resolved this run** → `last_seen` refreshed to now (even if it was
  already listed). This is what makes the listing survive DNS round-robin
  churn: an IP that rotates out for a few runs keeps its last `last_seen`
  and is only dropped once it has been absent longer than the retention
  window.
- **IP not resolved this run** → `last_seen` left unchanged
- **New IP** → added with `last_seen` = now
- **Purge** → any IP whose `last_seen` is older than the retention window
  is removed. Default retention is 30 days; `--retention 0` disables purge.

This solves the OPNsense problem where a domain like Tesla rotates its DNS
answers aggressively: the allowlist now persists across runs and only drops
an IP after it has genuinely been absent for the retention period, instead
of being rebuilt from scratch each cycle.

Run output reports the delta per domain:
- `N new IPs added` — IPs that appeared this run and were not previously listed
- `N purged` — IPs removed because `last_seen` is older than retention
- `total` — current number of IPs in the listing

## Tests

```bash
bash tests/test_grab_ip.sh        # IPv4/IPv6 validation
bash tests/test_merge_purge.sh    # JSON merge and purge logic
```

`test_grab_ip.sh` — unit tests for `grab_ip_is_valid_ip` covering IPv6 (full
form, `::` compression, zone ids, IPv4-mapped, invalid double `::`, wrong
group count) and IPv4 (standard, bounds 0/255, out-of-range octets, malformed
formats).

`test_merge_purge.sh` — tests for `grab_ip_merge_json` covering first run,
`last_seen` refresh, IP preservation when absent from a run (round-robin
survival), purge by retention cutoff, `retention 0` disabling purge, empty
resolution, and type preservation. All deterministic, no network.
